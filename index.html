临行前夜

发表于 2026-09-01 分类于 情绪

概述

凌晨零点四十二分。

我的心情复杂，我不想描述它，它是负面的。

今天第一次长期离开这个屋子。

前往一个未知的地方学习、生活。

网络冲浪的回忆历历在目。

人性的恶也在我的心里反反复复。

人的恶

我曾看见：

三个大学生租房，床底被刻意刻字、放置特异石头、桃木剑，“生意兴隆”倒置贴在上面，以及各种诡谲的布置。

大专生宿舍床底突然被刻意贴上未知符箓。

……

这种诡谲情况出现的概率小，但它客观存在。

它正映照人性的恶。

我怕了，尽管它出现的概率小。

我怕了，尽管我是唯物主义者。

最终决定

抵达前：装好行李，静定心神，虔诚拜神。

抵达后：万分谨慎，每日检查，一有异常则马上退出。

看法

或许我的行为会被人耻笑，甚至被几年后的自己耻笑。

“多此一举、过度谨慎、没安全感”

我不在乎。

我只在乎我认为现在做的对不对。

如果我觉得我是对的，我就去做。

使用体验

发表于 2026-08-30 分类于 回忆 ， 技术

对使用体验的追逐

开端

小学接触的几个奇人给我的计算机基础科普令我收获颇丰。

使我脱离了只用电脑玩游戏的想法。

“原来电脑的优化和其他部分也能这么有趣”

前期

脱离Windows后。

我发现Linux各式各样的发行版。

随后我开始疯狂地探索。

以下是我使用过的Linux系统

  • Ubuntu Linux
  • Deepin Linux
  • Manjaro Linux
  • Debian Linux
  • Arch Linux
  • Cachy OS
    ……

不一一列举。

后期

我连手机都刷入了各种新的系统和新的模块。

我感到一种耗尽新鲜感的麻木与空虚。

我已经体验了太多操作系统。

普通人或许一生都接触不到这么多。

我获得了什么？我失去了什么？

我获得了

  • 及时的快感
  • 空虚
  • 对结构性的强迫症
  • 电子设备的使用经验
  • 负面情绪

我失去了

  • 一部分情感
  • 一部分生活
  • 一部分社交
  • 一部分沟通

我想说

我总是在追求电子设备使用体验的精益求精。

但电子设备不全是生活。

我本末倒置了。

我或许后悔了，但过去回不来了。
我总是看着眼前的设备一次又一次枯坐到黄昏
这次我只想马上起身
去看夕阳落日，去体验真实的生活

初中

发表于 2026-08-30 分类于 回忆

初中

入学前夕

一边是对突然丧失社交的负面情绪，一边是突然增科的压力。

压力放大情绪，情绪放大逃避，我主动选择停摆。

或许这就是预兆，只是外部没人干预，自己也没有作为。

三年

用情绪遮掩事实，网络冲浪，逃避一切。

逃避考试、学校、沟通，继续逃避…….

直到逃避成了习惯，初中结束了，学业也一并荒废。

一句话

网络节制，直面现实，接受过去，杜绝不和现实接轨的思考，马上行动。

一首诗

往事成灰久寂寥，
人间偷得三分闲。
却教命运忽相逢，
空屋独坐又黄昏。
看淡人间三两事，
欲做旅人欲做仙。
